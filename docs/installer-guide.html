OD Installer — Help / Aide

Principe

OD Installer transforme une publication Windows en un seul EXE d’installation. Celui-ci embarque l’interface WPF, une archive ZIP standard, la licence, le manifeste et le désinstalleur.

Organisation validée. Le manifeste, la licence et la publication sont confinés dans le dossier du projet. Le dossier de sortie peut être personnalisé, y compris dans le parent du projet : c’est le cas de l’exemple OD.HarmoTools.

Format du manifeste

{
  "application": {
    "id": "My.App",
    "name": "My App",
    "version": "1.0.0",
    "publisher": "Example",
    "executable": "My.App.exe",
    "icon": "assets/app.ico",
    "welcomeImage": "assets/welcome.png"
  },
  "source": {
    "directory": "./publish"
  },
  "installation": {
    "scope": "perUser",
    "directory": "{LocalAppData}/Programs/My.App",
    "allowDirectorySelection": true
  },
  "license": {
    "file": "./LICENSE.txt",
    "requireAcceptance": true
  },
  "shortcuts": {
    "startMenu": true,
    "desktop": false
  },
  "output": {
    "directory": "./artifacts",
    "fileName": "My.App-Setup-1.0.0.exe"
  }
}
PropriétéRôle
application.idObligatoire ; clé de désinstallation Windows, sans caractère de nom de fichier invalide.
name, version, publisherInformations affichées ; la version doit être valide.
executableChemin relatif de l’EXE principal dans la publication ; il doit exister.
iconOptionnel ; réservé à une personnalisation future.
welcomeImageOptionnel ; chemin relatif vers un fichier PNG sous le dossier du manifeste. L’image est affichée sur le premier écran. Omettez la propriété ou laissez-la vide pour ne pas afficher d’image.
source.directoryRépertoire de publication, relatif au manifeste et obligatoirement contenu dans son dossier.
installation.scopeUniquement perUser dans cette V1.
installation.directoryDossier cible ; {LocalAppData} est remplacé pour l’utilisateur courant.
allowDirectorySelectionAutorise l’utilisateur à changer le dossier cible.
license.file, requireAcceptanceLicence relative au manifeste ; l’acceptation est obligatoire si la valeur est vraie.
shortcutsCréation facultative dans le Menu Démarrer et sur le Bureau.
output.directory, fileNameRépertoire de sortie personnalisable et nom de l’EXE ; fileName ne contient pas de chemin.

Pas à pas complet : OD.HarmoTools

  1. Créez le dossier de projet. Créez E:\OD. HarmoToolsInstaller\project.
  2. Copiez la publication. Copiez tout le contenu de E:\HarmoToolsPublish dans E:\OD. HarmoToolsInstaller\project\publish. Vérifiez notamment la présence de OD.HarmoTools.exe.
  3. Ajoutez la licence. Copiez la licence finale dans E:\OD. HarmoToolsInstaller\project\LICENSE.txt.
  4. Créez le manifeste. Créez E:\OD. HarmoToolsInstaller\project\installer.json avec le contenu ci-dessous.
{
  "application": {
    "id": "OD.HarmoTools",
    "name": "OD HarmoTools",
    "version": "1.0.0",
    "publisher": "Olivier Dahan",
    "executable": "OD.HarmoTools.exe",
    "welcomeImage": "./welcome.png"
  },
  "source": { "directory": "./publish" },
  "installation": {
    "scope": "perUser",
    "directory": "{LocalAppData}/Programs/OD.HarmoTools",
    "allowDirectorySelection": true
  },
  "license": { "file": "./LICENSE.txt", "requireAcceptance": true },
  "shortcuts": { "startMenu": true, "desktop": false },
  "output": {
    "directory": "..",
    "fileName": "OD.HarmoTools-Setup-1.0.0.exe"
  }
}
  1. Compilez le générateur. Ouvrez PowerShell dans E:\ODInstaller, puis exécutez dotnet build OdInstaller.slnx -c Release.
  2. Préparez le runtime autonome. Dans la même fenêtre, exécutez .\build-runtime.ps1. Cette étape construit l’installateur WPF et le désinstalleur sous forme autonome.
  3. Générez l’installeur. Exécutez : 
    dotnet run --project src\OdInstaller.Builder -c Release -- build "E:\OD. HarmoToolsInstaller\project\installer.json" --force
  4. Récupérez le résultat. Le fichier final est E:\OD. HarmoToolsInstaller\OD.HarmoTools-Setup-1.0.0.exe. Copiez-le ou lancez-le directement pour tester l’assistant.

Overview

OD Installer turns a Windows publication into one setup EXE. It embeds the WPF UI, a standard ZIP archive, license, manifest, and uninstaller.

Validated layout. The manifest, license, and published application stay inside the project folder. The output folder is customizable, including the project parent folder as used in the OD.HarmoTools example.

application.welcomeImage is optional. It must be a PNG path relative to the manifest and is displayed on the welcome screen. Omit it or leave it empty to display no image.

Manifest format

The formatted JSON example and property table are identical to the French version. Recognized fields are application.id/name/version/publisher/executable/icon/welcomeImage, source.directory, installation.scope/directory/allowDirectorySelection, license.file/requireAcceptance, shortcuts.startMenu/desktop, and output.directory/fileName. Only perUser is supported. Source and license paths remain below the manifest directory; the output directory may be any customized relative or absolute path.

Detailed walkthrough: OD.HarmoTools

  1. Create E:\OD. HarmoToolsInstaller\project.
  2. Copy every item from E:\HarmoToolsPublish to E:\OD. HarmoToolsInstaller\project\publish, including OD.HarmoTools.exe.
  3. Copy the final license to E:\OD. HarmoToolsInstaller\project\LICENSE.txt.
  4. Create E:\OD. HarmoToolsInstaller\project\installer.json with the formatted French example. Its output.directory is .., so output is the requested parent folder.
  5. In E:\ODInstaller, run dotnet build OdInstaller.slnx -c Release.
  6. Run .\build-runtime.ps1.
  7. Run dotnet run --project src\OdInstaller.Builder -c Release -- build "E:\OD. HarmoToolsInstaller\project\installer.json" --force.
  8. Take the completed installer from E:\OD. HarmoToolsInstaller\OD.HarmoTools-Setup-1.0.0.exe.
