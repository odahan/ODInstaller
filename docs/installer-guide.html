OD Installer — Help / Aide

Principe

OD Installer transforme une publication Windows en un seul EXE d’installation. Celui-ci embarque l’interface WPF, une archive ZIP standard, la licence, le manifeste et le désinstalleur.

Chemins explicites. Les chemins de la publication, de la licence, de l’image d’accueil et de la sortie sont obligatoirement absolus dans le JSON. Ils ne dépendent jamais du dossier où se trouve installer.json : un partage NAS, un autre disque ou tout autre emplacement est accepté.

Format du manifeste

{
  "application": {
    "id": "My.App",
    "name": "My App",
    "version": "1.0.0",
    "publisher": "Example",
    "executable": "My.App.exe",
    "icon": "\\\\nas\\branding\\My.App\\app.ico",
    "welcomeImage": "\\\\nas\\branding\\My.App\\welcome.png"
  },
  "source": {
    "directory": "E:\\Builds\\My.App\\publish"
  },
  "installation": {
    "scope": "perUser",
    "directory": "{LocalAppData}/Programs/My.App",
    "allowDirectorySelection": true
  },
  "license": {
    "file": "F:\\Licences\\My.App-LICENSE.txt",
    "requireAcceptance": true
  },
  "shortcuts": {
    "startMenu": true,
    "desktop": false
  },
  "output": {
    "directory": "E:\\Installers\\My.App",
    "fileName": "My.App-Setup-1.0.0.exe"
  }
}
PropriétéRôle
application.idObligatoire ; clé de désinstallation Windows, sans caractère de nom de fichier invalide.
name, version, publisherInformations affichées ; la version doit être valide.
executableChemin relatif de l’EXE principal dans la publication ; il doit exister.
iconOptionnel ; chemin absolu vers un fichier .ico. L’icône est installée avec l’application et utilisée pour les raccourcis du Bureau/Menu Démarrer et dans « Applications installées ».
welcomeImageOptionnel ; chemin absolu vers un PNG, y compris UNC (\\nas\partage\image.png). Omettez la propriété ou laissez-la vide pour ne pas afficher d’image.
source.directoryChemin absolu du répertoire de publication.
installation.scopeUniquement perUser dans cette V1.
installation.directoryDossier cible ; {LocalAppData} est remplacé pour l’utilisateur courant.
allowDirectorySelectionAutorise l’utilisateur à changer le dossier cible.
license.file, requireAcceptanceChemin absolu de la licence ; l’acceptation est obligatoire si la valeur est vraie.
shortcutsCréation facultative dans le Menu Démarrer et sur le Bureau.
output.directory, fileNameChemin absolu du répertoire de sortie et nom de l’EXE ; fileName ne contient pas de chemin.

Pas à pas complet : OD.HarmoTools

  1. Conservez vos fichiers à leur emplacement. La publication peut rester dans E:\HarmoToolsPublish, la licence dans F:\Licences\OD.HarmoTools-LICENSE.txt et l’image sur \\nas\branding\OD.HarmoTools\welcome.png.
  2. Créez le manifeste. Créez E:\OD. HarmoToolsInstaller\project\installer.json avec le contenu ci-dessous.
{
  "application": {
    "id": "OD.HarmoTools",
    "name": "OD HarmoTools",
    "version": "1.0.0",
    "publisher": "Olivier Dahan",
    "executable": "OD.HarmoTools.exe",
    "welcomeImage": "\\\\nas\\branding\\OD.HarmoTools\\welcome.png"
  },
  "source": { "directory": "E:\\HarmoToolsPublish" },
  "installation": {
    "scope": "perUser",
    "directory": "{LocalAppData}/Programs/OD.HarmoTools",
    "allowDirectorySelection": true
  },
  "license": { "file": "F:\\Licences\\OD.HarmoTools-LICENSE.txt", "requireAcceptance": true },
  "shortcuts": { "startMenu": true, "desktop": false },
  "output": {
    "directory": "E:\\Installers\\OD.HarmoTools",
    "fileName": "OD.HarmoTools-Setup-1.0.0.exe"
  }
}
  1. Compilez le générateur. Ouvrez PowerShell dans E:\ODInstaller, puis exécutez dotnet build OdInstaller.slnx -c Release.
  2. Préparez le runtime autonome. Dans la même fenêtre, exécutez .\build-runtime.ps1. Cette étape construit l’installateur WPF et le désinstalleur sous forme autonome.
  3. Générez l’installeur. Exécutez : 
    dotnet run --project src\OdInstaller.Builder -c Release -- build "E:\OD. HarmoToolsInstaller\project\installer.json" --force
  4. Récupérez le résultat. Le fichier final est E:\Installers\OD.HarmoTools\OD.HarmoTools-Setup-1.0.0.exe. Copiez-le ou lancez-le directement pour tester l’assistant.

Overview

OD Installer turns a Windows publication into one setup EXE. It embeds the WPF UI, a standard ZIP archive, license, manifest, and uninstaller.

Explicit paths. Publication, license, welcome image, and output paths must be absolute JSON paths. They never depend on the folder containing installer.json; NAS UNC paths and other drives are supported.

application.executable remains a relative path inside source.directory, because it identifies a file within the published application.

Manifest format

The formatted JSON example and property table are identical to the French version. source.directory, license.file, application.welcomeImage, and output.directory are absolute paths. Only perUser is supported.

Detailed walkthrough: OD.HarmoTools

  1. Keep the publish directory at E:\HarmoToolsPublish, the license at F:\Licences\OD.HarmoTools-LICENSE.txt, and the welcome image at \\nas\branding\OD.HarmoTools\welcome.png.
  2. Create the manifest anywhere, using the French example’s absolute paths.
  3. In E:\ODInstaller, run dotnet build OdInstaller.slnx -c Release, then .\build-runtime.ps1.
  4. Run dotnet run --project src\OdInstaller.Builder -c Release -- build "E:\OD. HarmoToolsInstaller\project\installer.json" --force.
  5. Take the installer from E:\Installers\OD.HarmoTools\OD.HarmoTools-Setup-1.0.0.exe.
